# Engineering

Everything a contributor needs to know about what Signboard does, how it is built and why.

| Section | What it holds |
|---|---|
| [Requirements](requirements/index.md) | Product Requirements Documents (PRDs): user stories with Given/When/Then acceptance criteria, one PRD per module |
| [Design](design/index.md) | Technical design documents: how each part works, including its data, API contract and tests |
| [Decisions](decisions/index.md) | Architecture Decision Records (ADRs): one significant decision per record, with context and consequences |
| [How we work](how-we-work.md) | Documentation first, testing, working in the open, the build journal, and the document templates |

Work flows in that order. A PRD story says what is needed, a design document says how, and ADRs record the decisions behind both. No code is written without an approved story and design ([ADR 0011](decisions/0011-documentation-first.md)).
