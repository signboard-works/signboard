# Requirements

Product Requirements Documents (PRDs) describe what Signboard does, as user stories with Given/When/Then acceptance criteria. Story IDs carry a module prefix (QUO, SO, JOB, INV, EML, MIG), and every acceptance criterion has an automated test that names its story ID ([ADR 0012](../decisions/0012-testing.md)).

| PRD | Covers | Status |
|---|---|---|
| [Quotes](prd-quotes.md) | Creating, pricing, versioning and sending quotes | Draft |
| [Sales orders](prd-sales-orders.md) | Turning accepted quotes into orders | Draft |
| [Jobs and kanban](prd-jobs-kanban.md) | Production jobs and the shop-floor board | Draft |
| [Invoices](prd-invoices.md) | Invoicing and accounting sync | Draft |
| [Customer email](prd-customer-email.md) | Sending documents and notifications to customers | Draft |
| [Migration](prd-migration.md) | Bringing data across from an existing system | Draft |

[Open questions](open-questions.md) lists what we still need to learn from the design partner shop.
